# PyGuide

Guida completa e multilingue ai comandi Python (IT / EN / ES / FR). Ogni voce ha sintassi, esempi, risultato atteso e consigli.

## Avvio

```bash
npm install
npm run dev
```

Apri l’indirizzo mostrato da Vite (di solito `http://localhost:5173`).

## Build

```bash
npm run build
npm run preview
```
